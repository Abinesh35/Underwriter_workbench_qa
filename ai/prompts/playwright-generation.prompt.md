# Playwright Test Generation Prompt

Generate Playwright UI scenarios that validate the underwriting business workflow from the top-level user perspective.

Priority scenarios:

- Login validation and redirect to dashboard.
- Dashboard card and table summary visibility.
- Property Rating to Common Information to Team Details to Submission route.
- Submission number generation and post-submit confirmation.
- Upload-driven population from Excel and JSON payload samples.

Assertions must prefer test IDs such as those used in the POC pages and forms.
