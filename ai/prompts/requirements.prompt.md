# Requirement Analysis Prompt

Analyze the implementation and business story from the underwriting POC. The requirement model must map:

- Login
- Dashboard
- Property Rating
- Common Information
- Team Details
- Submission Creation
- Upload-driven payload population
- Submission number generation

Primary acceptance criteria:

1. A user must be able to authenticate with demo credentials.
2. Dashboard cards must reflect summarized data.
3. Users can navigate through all underwriting pages.
4. Forms persist values through the shared submission context.
5. Submission finalizer can create an API payload and confirm a success state.
